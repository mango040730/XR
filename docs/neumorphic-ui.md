# 밝은 회색 뉴모피즘 UI

2026-11-09. 사용자가 첨부한 UI 이미지의 밝은 회색 표면·볼록한 버튼·오목한 입력 영역·둥근 카드·명확한 포커스와 선택 상태를 기존 화면에 적용했습니다. 이미지의 임시 영문 문구나 예시 기능은 복제하지 않고 기존 한국어 UI와 동작을 유지했습니다.

## 적용

- `ui/neumorphic.css`: 공통 표면 #e7e5e1, 텍스트 #303238, 보조 텍스트 #63666c, 포커스 #2674cb와 공통 그림자. 흰색 상단 하이라이트와 회색 하단 그림자로 버튼·카드의 입체감을 표현합니다. 활성/호버·눌림/선택·비활성 상태를 구분하고, 열린 안내 버튼은 호버 중에도 눌린 상태를 유지합니다. 비활성 버튼은 그림자를 제거합니다.
- `ui/fishing.css`와 `FishingHUD.ts`: 상단 브랜드/도구 막대, 안내 카드, 하단 상태/행동 패널, 모바일 이동 패드, 설정 안내 패널을 교체했습니다. 홈·도움말은 선형 SVG 아이콘, 그래픽/시연 인물은 실제 체크박스 기반 스위치입니다. 기존 data 속성과 이벤트 경로를 보존했습니다.
- 키보드 포커스는 3px 파란 테두리입니다. 스위치는 키보드 조작과 체크 상태를 유지하며 `role=switch`로 노출합니다. 모바일 아이콘 버튼에는 별도 접근성 이름을 제공하고, 안내 패널은 스크롤 중에도 닫기 버튼을 유지합니다. 동작 감소·강제 색상 모드용 대안을 포함합니다.
- 서비스 화면에도 같은 카드·입력·버튼·선택·달력·하단 내비게이션 스타일을 적용했습니다. 낚시 조작부와 서비스 메뉴의 하단 공간을 나누고, 모바일 상단 일시정지/종료 문구를 한 줄로 표시합니다. 비교용 `designReview` 원본 프레임은 테마 범위에서 제외했습니다.
- `DomPanelTexture.ts`와 `panelShadows.ts`: Cardboard의 실제 DOM 측정 기반 캔버스 패널에서도 외부/내부 그림자·새 테두리·선택 표시·아이콘 필터를 그립니다. CSS 그림자의 색상 내부 쉼표를 올바르게 구분하는 파서를 추가했습니다. 실시간 UI를 이미지로 고정한 것이 아닙니다.

## 보존과 검증

낚시터 전체 TS 파일과 Renderer.ts의 수정 전후 SHA-256이 같음을 대조했습니다. 실내·숲 팔레트, 건물·수조 구조, 물 셰이더, 조명, 카메라·이동·낚시 코드는 변경하지 않았습니다. 서버·백엔드·새 라이브러리도 추가하지 않았습니다.

- `npm run check`: 19개 파일 / 101개 단위 검사와 린트·타입·자산 검사·프로덕션 빌드 통과. 그림자 파서에서 다중 RGBA, inset, 음수 spread, 빈/잘못된 입력을 검사했습니다.
- Chromium 158 / Apple M4 / ANGLE Metal: 낚시 WASD·충돌·착석·포획·회수 회귀, 뉴모피즘 키보드 포커스/스위치/눌림/비활성 상태, 서비스 로그인·모바일 조작부 간격 검사 통과. PC/모바일의 전체 서비스 흐름도 통과했습니다.
- Cardboard: 실제 양안 캔버스와 드래그/시선 hit로 로그인부터 시뮬레이션·채팅·예약까지 진행하는 브라우저 검사 통과. 실제 헤드셋 착용 검증은 아닙니다.
- 현재 실행 중인 5174 서버에서 낚시 HUD/안내·로그인·서비스 모바일 화면 검사 3개를 통과했습니다. 기존 탭에 전체 페이지 갱신 신호를 보내고 문서가 재생성됨을 확인했습니다. 캡처를 직접 확인했습니다.
- Safari와 실제 VR 헤드셋은 미검증입니다. 서비스의 기존 1200×600 폼 패널 축소 방식은 유지하며, 낚시 HUD는 반응형으로 배치합니다.
