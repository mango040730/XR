# VR 실기기 검증 체크리스트

현재 상태: **모든 항목 미수행**. 호환 헤드셋/실제 컨트롤러가 없는 개발 환경에서 작성했습니다. 단위 테스트의 합성 XRFrame·Gamepad·이벤트와 Playwright의 WebGL 검사는 아래 항목을 통과한 것으로 간주하지 않습니다.

기록할 환경: 기기 모델/OS, 브라우저 버전, 컨트롤러/handedness, inputSource.profiles/mapping/axes, HTTPS 주소, 월드, 날짜, 재현 순서와 기대/실제 결과.

## 준비와 진입

- [ ] 안전한 실제 플레이 영역과 기기 경계를 설정한다. 가상 충돌은 사용자의 물리적 몸을 제지하지 않는다.
- [ ] 신뢰 가능한 HTTPS에서 실행한다. PC LAN의 HTTP 주소와 헤드셋 localhost의 차이를 확인한다.
- [ ] A에 PC로 진입하고 기본 VR 이동=teleport / 회전=snap을 확인한다.
- [ ] ENTER VR 승인/거절/취소를 각각 검사한다. 거절해도 PC 모드와 재시도가 가능해야 한다.
- [ ] 양안 렌더링, 1m 스케일, 머리 회전/위치 추적, local-floor 높이와 시작 방향을 확인한다. PC eyeHeight가 이중 가산되면 안 된다.

## 입력/이동

- [ ] 왼쪽/오른쪽 컨트롤러 연결 상태가 실제 inputSources와 일치한다. 연결/분리/재연결 때 기존 제스처가 확정되면 안 된다.
- [ ] 진입·포커스 복귀 때 스틱을 잡고 있어도 즉시 턴/이동하지 않는다. 중립 후 의도적으로 조작한다.
- [ ] 왼쪽 스틱 앞으로 유지하면 바닥 목적지를 표시하고 놓으면 유효할 때만 이동한다. 스퀴즈 유지/놓기도 검사한다.
- [ ] 초록/빨강 목적지와 오류 문구를 확인한다. 영역 밖·8m 초과·벽 뒤·기둥 안·바닥 가장자리·틈·낮은 머리 공간·다른 바닥 높이로 이동하지 않아야 한다.
- [ ] 오른쪽 좌우 스틱을 넘기면 기본 30도 한 번 회전하고, 잡고 있어도 반복하지 않는다. 중립 후 다시 회전한다.
- [ ] 머리를 원점에서 옮긴 상태의 스냅 턴에서도 머리/발 수평 위치가 밀리지 않는다.
- [ ] VR 종료 후 연속 이동을 선택해 재진입한다. 왼쪽 스틱이 머리 방향을 기준으로 움직이고 대각선 속도가 증가하지 않으며 벽/장애물/바닥 경계를 통과하지 않는다.
- [ ] 연속 회전은 별도 선택했을 때만 작동한다. 속도와 멀미·불편함을 기록한다. 첫 검증은 기본 텔레포트/스냅부터 수행한다.
- [ ] 컨트롤러 하나만 있을 때 가능한 조작을 확인한다. 오른쪽 단독은 전후 이동/턴이며 횡이동은 제공하지 않는다. thumbstick 없는/알 수 없는 mapping은 이동을 추측하지 않고 Ray 전용으로 안내한다.

## 추적·충돌·상호작용

- [ ] 실제 머리 이동도 같은 평면/AABB 제한을 사용한다. 벽 쪽으로 천천히 접근할 때 가상 몸이 통과하지 않고 경계 안내/암전이 나타나는지 확인한다.
- [ ] tracking origin reset/리센터 시 큰 가상 위치 점프 없이 발 위치를 유지하는지 확인한다.
- [ ] 추적 손실·세션 hidden/visible-blurred 때 이동·선택·텔레포트가 정지하고 화면이 가려지는지 검사한다. 복귀 때 중립 후 재조작한다.
- [ ] 가상 rig를 보정하는 방식이 실제 기기에서 불편함/드리프트를 유발하는지 기록한다. 이 정책은 실기기 승인 전이다.
- [ ] A/B 큐브 또는 GLB 받침대를 3m 이내에서 가리키면 강조되고 트리거의 표준 select로 같은 색 변경/복원 이벤트가 실행된다.
- [ ] 좌/우 Ray가 독립적으로 선택하고, 물리적 손을 가상 벽 너머로 뻗어도 머리 시야가 막힌 물체를 선택하지 못한다.
- [ ] VR 내부 텍스트의 크기·가독성·선택 메시지·경계/목적지 안내를 확인한다. 컨트롤러 자체 모델/고급 VR 메뉴는 아직 없다.

## 종료/월드 전환/회귀

- [ ] 기기 메뉴 또는 EXIT VR로 종료한다. PC 발 위치·최종 수평 시선·눈높이·화면 비율·WASD·마우스 잠금이 정상 복구되어야 한다.
- [ ] 세션 진입/종료를 3회 이상 반복하고 A/B/GLB에서 확인한다.
- [ ] VR 세션 종료 후 다른 월드 진입 시 spawn/입력/선택/hover/설정이 초기화되는지 확인한다. Engine.enterWorld의 프로그램식 요청도 세션 종료 후 전환해야 한다.
- [ ] 이전 월드의 메시·Ray 선택 상태·입력 이벤트가 누적되지 않는다. renderer/브라우저 메모리와 실제 프레임률·발열을 측정한다.

통과/실패/미수행과 실제 증거를 progress.md에 추가합니다. WebXR 드라이버·권한·양안·추적·물리 컨트롤러 움직임을 자동화로 완전히 검증했다고 보고하지 않습니다.

공식 확인 근거: [WebXR Device API](https://www.w3.org/TR/webxr/) (2026-10-29 Candidate Recommendation Draft), [WebXR Gamepads Module](https://www.w3.org/TR/webxr-gamepads-module-1/) (2025-07-07 Working Draft), [Three.js WebXRManager](https://threejs.org/docs/pages/WebXRManager.html). 설치된 Three.js r187의 소스/타입과 호환성을 확인했습니다.
