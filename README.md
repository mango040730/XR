# 공간 VR

배포 주소: https://mango040730.github.io/XR/

`공간.glb`를 바탕으로 만든 UI 없는 WebXR 공간입니다.
화면에는 3D 캔버스만 표시됩니다. 상부는 지붕 없이 열려 있으며 파란 상부 배경 대신 밝은 중립색 배경을 사용합니다. 원본은 `public/models/space.glb`에 보존했습니다.

단면은 **높은 블루길 → 원형 계단 공간 → 낮은 중앙 원형 공간**입니다. 직전 가운데 좌석 층의 높이 약 5.63m를 새 최고 높이로 삼아 전체 3개 좌석 층을 고르게 낮췄습니다. 중앙 바닥은 높이 1.15m를 유지하며 총 단차는 약 6.72m에서 4.48m로 줄었습니다. 좌석 단의 바닥 높이는 안쪽부터 약 2.64·4.14·5.63m이며 각 단 차이는 약 1.49m입니다. 블루길은 격자 없는 벨벳 카펫이며 가장 바깥 좌석 단과 같은 약 5.63m 높이로 이어집니다. 가구 크기는 유지하고 각 단 위로 함께 이동합니다. 높이는 `src/space-levels.js`에서 함께 관리합니다.

네 방향의 좁은 이동 계단은 15단으로 한 단 높이 약 0.30m, 디딤 깊이 약 0.60m입니다. 넓은 원형 좌석 계단(3단)과 하나의 연속된 형상으로 연결되며 위쪽 면과 높이가 다른 측면까지 빈틈없이 이어집니다. 가장 바깥 단과 블루길도 같은 외곽선을 공유합니다.

원형 좌석 단은 깊이 4m에서 3m로 줄였습니다. 전체 공간 지름 90.4m와 블루길 폭 10m는 유지하고, 중앙 원형 공간 반경을 23.2m에서 26.2m로 넓혔습니다. 세 단 앞쪽 가장자리에는 나뭇결이 보이는 갈색 상판·앞쪽 턱과 앞판·양끝 지지판으로 구성된 곡선 일체형 책상 92개를 배치했습니다. 각 책상은 1~4인용이며 1인용 19개·2인용 25개·3인용 23개·4인용 25개를 섞어 총 238석입니다. 길이는 약 1.7~9.2m로 인원 수에 따라 달라집니다. 각 단 둘레의 약 84~85%를 책상으로 채워 넓은 공백을 줄였고, 같은 구간 안의 책상 사이 간격은 약 0.35m입니다. 책상 사이에 있던 원형 스툴 2개는 받침·쿠션까지 제거했습니다. 네 방향 계단을 비운 뒤 남은 곡선 구간에 맞춰 책상 길이를 계산합니다. 책상 형태는 목재 다리로 변경하기 전의 일체형 구조로 복원했고 갈색 나뭇결은 유지했습니다. 원형 계단 의자는 프레임과 좌판·등받이 모두 갈색 계열입니다. 의자는 모두 책상 바깥쪽 한 줄에서 중앙 원형 공간을 바라봅니다. 의자 뒤쪽에는 최소 1.2m 통로를 확보했고 네 방향 이동 계단은 비워두었습니다. 큰 화분은 크기를 유지해 블루길 안쪽으로 옮겼습니다. 수평 치수는 `src/space-layout.js`에서 관리합니다.

블루길은 폭 10m를 유지합니다(내곽 반경 35.2m, 외곽 반경 45.2m). 외곽 벽과 이동 범위도 함께 확장했습니다. 원형 계단·블루길 모두 보행·VR 이동이 가능하며 UI는 추가하지 않습니다. 편집은 `src/prepare-space.js`에서 원본 로딩 후 적용합니다.

외곽 벽은 높이 6.8m의 360도 원형 디지털 스크린입니다. 얇은 프레임과 은은한 발광·광택으로 빈 대기 화면만 표현하며, UI나 문구는 넣지 않았습니다. 기존 반원 벽의 간판·문·기둥·파도 장식은 제거했습니다. `src/digital-wall.js`의 연속된 단일 화면 표면에 추후 콘텐츠를 적용할 수 있습니다.

공간은 최신 참고 이미지의 매끈한 제품 렌더 미니어처 스타일입니다. 소파·쿠션·둥근 좌석 189개 부품은 실제 곡면을 부드럽게 다듬고 각 부품의 원래 외곽과 크기를 유지합니다. 책상은 3.5cm의 둥근 베벨을 사용합니다. 소파는 새틴, 계단 책상은 갈색 목재 나뭇결과 은은한 마감, 나머지 가구 프레임은 유광 도장, 화분은 도자기, 하부 받침은 금속으로 재질별 광택을 구분하며 따뜻한 주광·환경 반사와 선명한 접촉 그림자로 입체감을 표현합니다. 주요 딥블루·크림·코랄·골드 옐로 팔레트와 공간 배치·통로는 유지합니다. 스타일 처리는 `src/clay-style.js`에서 적용하며 디지털 스크린과 블루 벨벳은 기존 재질을 유지합니다.

## 실행

```sh
npm install
npm run dev
```

배포용 빌드: `npm run build` (`dist/`).

검사: `npm run check`. GitHub의 main 브랜치에 업로드하면 Actions에서 검사·빌드 후 GitHub Pages로 자동 배포합니다. Pages 빌드는 `VITE_BASE_PATH=/XR/`로 실행합니다.

## 조작

- PC: 화면 클릭 후 마우스로 둘러보기, WASD/방향키 이동, Shift 빠르게 걷기, Esc 마우스 해제, R 시작 위치.
- 모바일: 한 손가락 드래그로 둘러보기, 두 손가락을 대고 있으면 앞으로 이동.
- WebXR 지원 헤드셋: HTTPS 주소를 헤드셋 브라우저에서 열고 공간을 클릭하면 VR 진입. 키보드가 있다면 V로도 진입.
- VR: 왼쪽 스틱 이동, 오른쪽 스틱 30도 회전, 컨트롤러로 바닥을 가리키고 트리거를 눌렀다 놓으면 15m 이내 보이는 바닥으로 이동. 종료는 헤드셋의 시스템 메뉴.

브라우저의 VR 접근 권한창은 브라우저가 표시합니다. 별도의 VR 버튼이나 HUD는 없습니다.
WebXR은 HTTPS 또는 localhost에서 사용할 수 있습니다. 헤드셋을 사용하지 않는 PC·모바일에서는 일반 3D 탐색으로 동작합니다.
실제 헤드셋에서의 입체 표시와 컨트롤러 동작은 기기 검증이 필요합니다.
