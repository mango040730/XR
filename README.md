# 공간 VR

배포 주소: https://mango040730.github.io/XR/

화면에는 공간만 표시하는 WebXR 모임 공간입니다. UI·HUD·메뉴·문구는 없습니다. 지붕은 열려 있고 밝은 중립색 배경을 사용합니다.

## 중앙 모임 공간

사용자가 확인한 **구역별 4~10인** 기준으로 중앙의 여섯 구역을 구성했습니다.

| 구역 | 지정 좌석 수 |
| --- | ---: |
| 계단형 원형 라운지 | 10 |
| 큰 곡선 소파 | 8 |
| 작은 휴식 공간 | 4 |
| 원형 미팅 공간 | 6 |
| 중앙 곡선 모임 공간 | 10 |
| 오른쪽 테이블 소파 | 6 |

총 44개의 지정 좌석이 실제 개별 쿠션·의자 메시로 존재합니다. 일반 좌판 높이는 0.46m, 원형 책상 상면은 0.79m이며, 계단형 라운지는 세 줄에 3·3·4개의 쿠션을 나누어 배치했습니다.

중앙 가구는 `src/clay-gatherings.js`에서 실제 곡면으로 다시 만듭니다. 각진 폴리곤을 노멀만 바꿔 감추지 않고, 곡선 가구는 둘레 192구간·둥근 베벨 10구간, 의자는 둥근 박스, 테이블은 96분할 회전체로 구성합니다. 코랄 쿠션과 아이보리 구조물을 분리하고 반무광 클레이 재질을 사용합니다. 화분의 형태·색상·흙·테두리·돌은 유지하고, 모든 식물을 최신 참고 이미지의 낮고 넓은 파스텔 혼합 화단으로 교체했습니다. 둥근 초록 덩어리 5개와 길쭉한 입체 잎 사이에 연보라·분홍·노랑 튤립 봉오리, 버터색·살구색 컵 모양 꽃, 분홍·노랑 데이지를 높낮이 다르게 배치합니다. 큰 화분은 참고 이미지의 11송이 구성, 작은 탁상 화분은 같은 종류의 5송이 구성으로 총 13개 화분에 125송이를 적용합니다. 식물 형상은 `src/clay-flower-bed.js`에서 관리하고 꽃잎·잎·돌은 재질별로 묶어 렌더링 부하를 줄입니다.

기존 곡선 구역의 좌우 관계, 앞쪽 타원형 화분, 뒤쪽이 0.28m 높은 실제 바닥 단차는 유지합니다. X 표시된 테이블과 작은 둥근 스툴은 넣지 않습니다. 중앙 가구와 모든 화분은 해당 바닥에 접지하고, 계단 앞 순환 공간을 확보합니다.

## 공간 비례

좌석 규모에 맞춰 중앙 가구와 외곽 계단·블루길을 함께 줄였습니다.

| 항목 | 현재 치수 |
| --- | ---: |
| 중앙 바닥 지름 | 25m |
| 전체 원형 본체 지름 | 51m |
| 넓은 계단 한 단 깊이 | 2.8m |
| 블루 벨벳 길 폭 | 4.6m |
| 중앙 앞쪽 / 뒤쪽 바닥 높이 | 1.15m / 1.43m |
| 블루길 바닥 높이 | 3.85m |
| 이동 계단 | 9단, 각 0.30m |
| 디지털 스크린 높이 | 4.8m |

외곽 아래 두 단에는 곡선 캡슐형 상판과 두 판형 다리의 테이블 20개와 안쪽을 바라보는 파이프 의자 37개를 배치합니다. 아래층 11개·위층 9개이며, 1·2·3·4인용은 9·7·2·2개(45%·35%·10%·10%)입니다. `src/terrace-lounge-layout.js`에서 소형 테이블 2~3개 모임·독립석·긴 빈 구간을 비대칭으로 구성합니다. 길이 1.45·2.35·3.15·3.95m, 깊이 0.70m, 상판 두께 0.075m, 높이 0.79m와 기존 판형 다리의 형상과 계단 구조는 유지합니다. 지지 다리는 상판 양끝에서 0.24m 안쪽에 놓고, 의자 줄 간격은 상판 길이와 별도로 유지해 바깥 의자까지 두 다리 사이에 들어갑니다. 라운지 포켓과 독립석 구성은 유지하며 길어진 테이블 사이 통행 간격을 확보합니다.

계단 테이블과 의자 프레임은 `src/terrace-smoked-wood.js`의 저채도 스모크드 회갈색 #615D59 무광 목재입니다. [Poly Haven Wood Table 001](https://polyhaven.com/a/wood_table_001)의 CC0 사진 기반 색상 텍스처를 자체 호스팅하고, 붉은 원색을 제거한 미세한 명도 차이만 낮은 대비로 사용합니다. 사인파 결은 사용하지 않습니다. 상판은 곡선 테두리를 따라 휘지 않는 직선 판재 좌표, 받침과 의자 프레임은 부재 방향의 실제 미터 단위 좌표를 사용합니다. 사진 샘플 위치·방향을 가구별로 달리하고 연속 블렌딩·밉맵·거리별 디테일 완화로 반복과 경계를 줄입니다. 거친 범프·노멀·변위·AO 사진은 적용하지 않습니다. 출처·라이선스·파일 해시는 `public/textures/wood-source.json`에 있습니다.

파스텔 블루 #A5BCD5 천 쿠션과 좌판 높이 0.46m는 유지합니다. 포켓 안 테이블 사이에는 약 0.95~1.05m, 의자 뒤에는 1.4m 이상의 공간이 있습니다. 층마다 7.5m 이상 비운 구간을 두고 위아래 가구를 엇갈리게 배치합니다. 맨윗단은 가구 없이 윗면만 블루 카펫이며 수직 앞면·옆면은 연그레이입니다. 넓은 단과 좁은 이동 계단은 하나의 연속 형상이며 카펫에는 격자·체크 무늬가 없습니다.

색상은 중앙 쿠션 #D94224, 계단 책상·의자 프레임 #615D59 무광 우드, 중앙 책상·의자 #E99804, 계단 의자 천 쿠션 #A5BCD5, 바닥 #F4CFB8, 구조물 #FDE8DC, 블루길 #203D85, 계단 #CBCBCB입니다. 따뜻한 조명과 부드러운 그림자, 브라우저의 GTAO 접촉 음영을 사용합니다. VR은 WebXR 양안 렌더링을 직접 사용합니다.

## 출입구와 시작 시점

정면 디스플레이의 폭 약 4.4m·높이 약 3.5m 개구부는 실제 통과할 수 있습니다. 둥근 아이보리 문틀과 얇은 따뜻한 조명만 두고, 위쪽 화면은 계속 이어집니다. 입구 연결 바닥은 블루길과 같은 높이·재질이며 원형 카펫의 실제 외곽선과 맞닿습니다.

접속과 R키 복귀는 `(0, 약 3.875, 26.6)`의 입구에서 중앙(-Z)을 바라보는 시점입니다. 눈높이는 바닥에서 1.65m입니다. 이동과 VR 텔레포트는 출입구에 한해서 원형 경계 밖의 연결 바닥까지 허용합니다.

## 코드와 원본

현재 실행 경로는 `src/main.js` → `src/compact-space.js`의 `prepareGatheringSpace`입니다. 치수·배치·좌석 수는 `src/gathering-layout.js`, 출입구 공통 동작은 `src/entrance.js`에서 관리합니다. 렌더링·충돌·착지 바닥은 동일한 최종 장면으로 구성합니다.

원본 `public/models/space.glb`와 첨부 개별 GLB 6종(`public/models/furniture-v2/`)은 파일을 변경하지 않고 보존합니다. 새 실행 장면은 외곽 의자를 `src/terrace-tube-chair.js`의 파이프 프레임·파스텔 블루 천 쿠션 의자로 만들고 중앙은 클레이 모임 가구로 재구성합니다. 이전 `prepareSpace` 경로는 기존 모델 편집의 회귀 검사에 남겨 두었습니다.

## 실행과 검사

```sh
npm ci
npm run dev
npm run check
```

GitHub main에 업로드하면 Actions에서 검사·빌드 후 Pages로 배포합니다. Pages 빌드는 `VITE_BASE_PATH=/XR/`를 사용합니다. 모델 검사에는 원본 보존, 실제 좌석 수·좌판 피킹·접지·비관통, 전체 충돌 병합, 입구·계단·중앙 통로의 연속 보행이 포함됩니다.

별도 Chrome을 포트 9223으로 실행한 상태에서 `node scripts/check-browser-movement.mjs <URL>`로 실제 시작 위치·출입구 통과·W/S·방향키·두 손가락 이동·화면 크기 변경과 브라우저 오류를 확인할 수 있습니다.

## 조작

- PC: 화면 클릭 후 마우스로 둘러보기, WASD/방향키 이동, Shift 빠르게 걷기, Esc 마우스 해제, R 입구로 복귀.
- 모바일: 한 손가락 드래그로 둘러보기, 두 손가락을 대고 있으면 앞으로 이동.
- WebXR: 공간 클릭 또는 V키로 VR 진입, 왼쪽 스틱 이동, 오른쪽 스틱 30도 회전, 트리거로 보이는 바닥에 텔레포트.

WebXR은 HTTPS 또는 localhost에서 사용할 수 있습니다. 브라우저의 VR 권한창 외에 별도 UI는 없습니다. 실제 VR 헤드셋과 컨트롤러는 실기 검증하지 않았습니다.
