물리 헤드셋·실제 휴대폰 센서/성능은 별도 검증 대상입니다. Cardboard 드래그·시선 검사는 실제 VR 하드웨어 검증을 대신하지 않습니다.

## 기본 홈과 시작 좌석 — 2026-11-11

일반 앱의 기본 홈은 항상 모드 선택 UI입니다. `#my-room`도 `#modes`로 연결되며 M/Esc로 홈 카드를 숨기지 않습니다. 첫 접속 시 마이룸을 불러오면 책장 앞 `Signature owner lounge chair`([1.65,.02,2.05])에 앉은 시점으로 시작합니다. GLB 가구는 +Z, 카메라는 -Z를 바라보므로 화면용 yaw는 .5rad입니다. 앉은 눈높이는 발 기준1.12m이며 첫 이동 입력에서 검증된 의자 앞 [2,.02,.65]로 일어나 공통 이동/충돌을 사용합니다. 이 동작은 첫 화면용 로컬 착석이며 서버 좌석 점유/예약은 변경하지 않습니다. 기존 서버 좌석은 이동 키로 해제하지 않습니다. 일반 앱 조립 단계에서 첫 착석과 콘텐츠 이후 복귀를 구분합니다. 공통 마이룸 spawn과 기존 서버 카탈로그의 도착 위치는 방문 앞 [2.23,.02,-2.85], yaw π로 통일합니다.

## 방문을 통한 공간 전환 — 2026-11-11

모드 선택 시 공통 충돌 경계로 검증한 경로를 따라 방문으로 이동합니다. 원본 MainPortal의 문짝·손잡이·장식을 힌지로 묶어 열고, 문턱으로 들어가며 화면을 전환합니다. 움직이는 문은 정적 배칭에서 제외하고 기존 월드가 자원을 소유합니다. 창문/벽/가구나 원본 GLB 파일은 수정하지 않습니다. 최초 좌석→일어서기→통로→문 열기→콘텐츠 전환 순서이며, 콘텐츠 종료 후 복귀는 방문 앞에서 방 안을 바라보는 서 있는 시점입니다. 이동 중 취소/뒤로 가기는 원래 자세와 착석 정책을 복구하고 늦은 전환 완료를 적용하지 않습니다. 콘텐츠 평가의 마지막 장면 고정은 유지합니다. 모션 감소 설정·Cardboard/XR은 강제 이동을 생략하고 짧게 전환합니다. 실제 VR 기기는 미검증입니다.
