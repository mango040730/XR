# 물고기 자유 유영 — 2026-11-09

고정 반지름과 각도로 위치를 계산하던 원형·타원형 경로를 제거했습니다. `FishSchool`이 물고기별 목표 위치·속도·방향을 보관합니다. 목표에 가까워지거나 8~21초가 지나면 수조 안의 다른 위치와 깊이를 선택합니다. 모든 물고기가 같은 시간에 방향을 바꾸지 않으며, 이동 중에는 목표 방향으로 서서히 회전합니다.

병어는 느리게, 고등어는 비교적 빠르게, 숭어는 중간 속도로 움직이며 개체별 차이도 있습니다. 목표에 다가가거나 큰 방향 전환을 할 때 감속하고 가끔 짧게 느려집니다. 몸의 기울기와 꼬리 움직임은 이동 방향·속도에 맞춰 연결됩니다. 주변 물고기와 가까우면 경로를 벌리고, 벽에 접근하면 미리 안쪽으로 틉니다. 이는 국소 회피이며 정밀한 물리 충돌 시뮬레이션은 아닙니다.

실제 메시의 크기로 수면·바닥·벽의 여유 공간을 계산합니다. 1/60초 고정 간격으로 계산하고 긴 프레임은 0.2초로 제한하여 탭 복귀 때 몇 분의 이동을 한꺼번에 진행하지 않습니다. 새 타이머·외부 라이브러리·GPU 자원은 추가하지 않았습니다. 물 셰이더, 모델 3종/6마리, 흰색 수조 바닥, 포획 시간 30~120초, 실내/숲 팔레트와 UI는 그대로입니다.

## 검증

- Node: 전체 21개 파일 / 109개 테스트, 린트·타입·자산·프로덕션 빌드 통과.
- 새 로직 검사: 2분간 반지름·가로·세로·깊이 변화, 3분간 회전한 실제 메시 전체의 수조 경계 준수 및 진행 방향 일치, 30/60fps 경로 일치, 긴 탭 공백에서 순간 이동 방지.
- Chromium 158 / Apple M4 / ANGLE Metal: 독립 유영 12초 관측·저사양 모드·시점 전환, 기존 수면, 이동·착석·30~120초 포획·회수·기립 회귀 3개 통과. 런타임·콘솔·네트워크 오류 없음.
- Safari와 실제 VR 헤드셋 검증은 수행하지 않았습니다. 기존 Three.js 500KB 번들 크기 경고가 남습니다.

현재 개발 서버 `http://127.0.0.1:5174/?fishing&swimming=free`에서도 새 소스 응답과 12초 유영을 확인했습니다. HTML 내용은 유지하고 수정 시각만 갱신해 전체 새로고침을 확인했습니다. 실서버 검사 1개 통과. 기존 실내/수조/모델/물/낚시/UI/Renderer 25개 파일의 해시는 수정 전과 같습니다.
