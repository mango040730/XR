충돌은 평평한 바닥과 정적 AABB 범위입니다. capsule/triangle, 계단/경사/중력, 물리적 신체를 실제로 제지하는 기능은 없습니다. VR의 가상 몸 위치를 제한하고 경계/추적 이상에는 화면을 가리는 보완 처리를 코드로 구현했습니다. 편의성·실제 추적 안정성은 장치 검증 전입니다.

기존 WorldManager, ModelLoader, CollisionSystem, registry를 교체하지 않았습니다. 새 SDK·물리 엔진·서버를 추가하지 않았고 제외 요청된 회원가입·최종 디자인·아바타·멀티플레이·마이룸·음성·DB는 구현하지 않았습니다.
