# 공간 VR

배포 주소: https://mango040730.github.io/XR/

`공간.glb`를 바탕으로 만든 UI 없는 WebXR 공간입니다.
화면에는 3D 캔버스만 표시됩니다. 상부는 지붕 없이 열려 있으며 파란 상부 배경 대신 밝은 중립색 배경을 사용합니다. 원본은 `public/models/space.glb`에 보존했습니다.

단면은 **높은 블루길 → 원형 계단 공간 → 낮은 중앙 원형 공간**입니다. 직전 가운데 좌석 층의 높이 약 5.63m를 새 최고 높이로 삼아 전체 3개 좌석 층을 고르게 낮췄습니다. 중앙 바닥은 높이 1.15m를 유지하며 총 단차는 약 6.72m에서 4.48m로 줄었습니다. 원형 단의 바닥 높이는 안쪽부터 약 2.64·4.14·5.63m이며 각 단 차이는 약 1.49m입니다. 블루길은 격자 없는 벨벳 카펫이며 가장 바깥 좌석 단과 같은 약 5.63m 높이로 이어집니다. 책상과 의자는 아래 두 단에만 배치하고 맨윗단은 가구 없이 비워 둡니다. 높이는 `src/space-levels.js`에서 함께 관리합니다.

네 방향의 좁은 이동 계단은 15단으로 한 단 높이 약 0.30m, 디딤 깊이 약 0.60m입니다. 넓은 원형 좌석 계단(3단)과 하나의 연속된 형상으로 연결되며 위쪽 면과 높이가 다른 측면까지 빈틈없이 이어집니다. 가장 바깥 단과 블루길도 같은 외곽선을 공유합니다.

원형 단의 깊이는 3m, 전체 공간 지름은 90.4m, 중앙 바닥 반경은 26.2m입니다. 책상과 의자는 아래 두 단에만 있으며 맨윗단의 가구는 제거했습니다. 아래층 책상 28개·가운데층 32개로 총 60개이고, 1인용 11개·2인용 17개·3인용 15개·4인용 17개로 총 158석입니다. 기존 일체형 상판·앞쪽 턱/앞판·양끝 지지판을 유지하며 책상과 의자는 #E99804입니다. 책상은 색상을 흐리지 않는 은은한 나뭇결 명암·요철을 사용합니다. 가구가 있는 두 단 둘레의 80% 이상을 채우고 책상 간격 약 0.35m, 의자 뒤 1.2m 통로와 네 이동 계단을 유지합니다. 의자는 중앙을 보는 바깥쪽 한 줄에만 있으며 원형 스툴 2개는 제거된 상태입니다. 큰 화분은 블루길 안쪽에 있습니다.

사용자 지정 색상은 `src/space-colors.js`에서 관리합니다. 중앙 코랄 좌석 #ED715D, 계단 책상·의자 #E99804, 중앙 바닥 #F4CFB8, 조형물·소파 등받이·구조물 #FDE8DC, 원형 블루길/레일 #1A3880입니다. 원본에서 한 재질로 묶인 소파 좌판·등받이는 형상을 유지한 채 부품별 색상으로 구분했습니다.

블루길은 폭 10m를 유지합니다(내곽 반경 35.2m, 외곽 반경 45.2m). 외곽 벽과 이동 범위도 함께 확장했습니다. 원형 계단·블루길 모두 보행·VR 이동이 가능하며 UI는 추가하지 않습니다. 편집은 `src/prepare-space.js`에서 원본 로딩 후 적용합니다.

외곽 벽은 높이 6.8m의 360도 원형 디지털 스크린입니다. 얇은 프레임과 은은한 발광·광택으로 빈 대기 화면만 표현하며, UI나 문구는 넣지 않았습니다. 기존 반원 벽의 간판·문·기둥·파도 장식은 제거했습니다. `src/digital-wall.js`의 연속된 단일 화면 표면에 추후 콘텐츠를 적용할 수 있습니다.

공간은 최신 참고 이미지의 매끈한 제품 렌더 미니어처 스타일입니다. 소파·쿠션·둥근 좌석 189개 부품은 실제 곡면을 부드럽게 다듬고 각 부품의 원래 외곽과 크기를 유지합니다. 책상은 3.5cm의 둥근 베벨을 사용합니다. 소파는 새틴, 계단 책상은 지정 골드 색상과 은은한 나뭇결 마감, 나머지 가구 프레임은 유광 도장, 화분은 도자기, 하부 받침은 금속으로 재질별 광택을 구분하며 따뜻한 주광·환경 반사와 선명한 접촉 그림자로 입체감을 표현합니다. 사용자 지정 팔레트와 공간 구성·통로를 유지합니다. 스타일 처리는 `src/clay-style.js`에서 적용하며 디지털 스크린과 블루 벨벳은 기존 재질을 유지합니다.

## 실행

```sh
npm install
npm run dev
```

배포용 빌드: `npm run build` (`dist/`).

검사: `npm run check`. GitHub의 main 브랜치에 업로드하면 Actions에서 검사·빌드 후 GitHub Pages로 자동 배포합니다. Pages 빌드는 `VITE_BASE_PATH=/XR/`로 실행합니다.

## 조작

- PC: 화면 클릭 후 마우스로 둘러보기, WASD/방향키 이동, Shift 빠르게 걷기, Esc 마우스 해제, R 시작 위치.
- 모바일: 한 손가락 드래그로 둘러보기, 두 손가락을 대고 있으면 앞으로 이동.
- WebXR 지원 헤드셋: HTTPS 주소를 헤드셋 브라우저에서 열고 공간을 클릭하면 VR 진입. 키보드가 있다면 V로도 진입.
- VR: 왼쪽 스틱 이동, 오른쪽 스틱 30도 회전, 컨트롤러로 바닥을 가리키고 트리거를 눌렀다 놓으면 15m 이내 보이는 바닥으로 이동. 종료는 헤드셋의 시스템 메뉴.

브라우저의 VR 접근 권한창은 브라우저가 표시합니다. 별도의 VR 버튼이나 HUD는 없습니다.
WebXR은 HTTPS 또는 localhost에서 사용할 수 있습니다. 헤드셋을 사용하지 않는 PC·모바일에서는 일반 3D 탐색으로 동작합니다.
실제 헤드셋에서의 입체 표시와 컨트롤러 동작은 기기 검증이 필요합니다.
