# 공간 VR

배포 주소: https://mango040730.github.io/XR/

`공간.glb`를 바탕으로 만든 UI 없는 WebXR 공간입니다.
화면에는 3D 캔버스만 표시됩니다. 원본은 `public/models/space.glb`에 보존했습니다.

단면은 **높은 블루길 → 원형 계단 공간 → 낮은 중앙 원형 공간**입니다. 중앙 바닥 높이 1.15m를 유지하고 전체 단차를 직전 약 1.68m에서 6.72m로 4배 높였습니다. 블루길은 격자 없는 벨벳 카펫이며 계단 상단과 같은 높이 약 7.87m로 이어집니다. 이동 계단은 24단으로 한 단 약 0.28m, 넓은 좌석 계단은 3단으로 한 단 약 2.24m입니다. 가구 크기는 유지해 각 단 위에 배치합니다. 높이는 `src/space-levels.js`에서 함께 관리합니다.

네 방향의 좁은 이동 계단(24단)과 넓은 원형 좌석 계단(3단)은 하나의 연속된 형상입니다. 두 계단 사이의 위쪽 면과 높이가 다른 측면까지 이어져 빈 틈이 없으며, 최상단과 블루길도 같은 외곽선을 공유합니다.

원형 좌석 단은 깊이 4m에서 3m로 줄였습니다. 전체 공간 지름 90.4m와 블루길 폭 10m는 유지하고, 중앙 원형 공간 반경을 23.2m에서 26.2m로 넓혔습니다. 세 단 앞쪽 가장자리에는 상판·낮은 안쪽 등판·양끝 지지판이 연결된 곡선 목재 일체형 책상 34개를 배치했습니다. 길이 1.6·3.2·4.8·6.4m의 1~4인용 책상을 일정한 비정형 패턴으로 섞어 총 83석을 배치했습니다. 의자는 모두 책상 바깥쪽 한 줄에서 중앙 원형 공간을 바라봅니다. 의자 뒤쪽에는 최소 1.2m 통로를 확보했고 네 방향 이동 계단과 스툴 주변은 비워두었습니다. 큰 화분은 크기를 유지해 블루길 안쪽으로 옮겼습니다. 수평 치수는 `src/space-layout.js`에서 관리합니다.

블루길은 폭 10m를 유지합니다(내곽 반경 35.2m, 외곽 반경 45.2m). 외곽 벽과 이동 범위도 함께 확장했습니다. 원형 계단·블루길 모두 보행·VR 이동이 가능하며 UI는 추가하지 않습니다. 편집은 `src/prepare-space.js`에서 원본 로딩 후 적용합니다.

외곽 벽은 높이 6.8m의 360도 원형 디지털 스크린입니다. 얇은 프레임과 은은한 발광·광택으로 빈 대기 화면만 표현하며, UI나 문구는 넣지 않았습니다. 기존 반원 벽의 간판·문·기둥·파도 장식은 제거했습니다. `src/digital-wall.js`의 연속된 단일 화면 표면에 추후 콘텐츠를 적용할 수 있습니다.

공간은 부드러운 클레이 미니어처 스타일입니다. 가구·쿠션·식재의 실제 곡면을 세분화하고 노멀을 매끈하게 연결했으며, 은은한 코랄·세이지·허니우드 색과 무광 재질·따뜻한 조명을 사용합니다. 각 부품의 원래 치수와 바닥 접점은 보존합니다. 스타일 처리는 `src/clay-style.js`에서 적용하며 디지털 스크린과 블루 벨벳은 각각의 재질을 유지합니다.

## 실행

```sh
npm install
npm run dev
```

배포용 빌드: `npm run build` (`dist/`).

검사: `npm run check`. GitHub의 main 브랜치에 업로드하면 Actions에서 검사·빌드 후 GitHub Pages로 자동 배포합니다. Pages 빌드는 `VITE_BASE_PATH=/XR/`로 실행합니다.

## 조작

- PC: 화면 클릭 후 마우스로 둘러보기, WASD/방향키 이동, Shift 빠르게 걷기, Esc 마우스 해제, R 시작 위치.
- 모바일: 한 손가락 드래그로 둘러보기, 두 손가락을 대고 있으면 앞으로 이동.
- WebXR 지원 헤드셋: HTTPS 주소를 헤드셋 브라우저에서 열고 공간을 클릭하면 VR 진입. 키보드가 있다면 V로도 진입.
- VR: 왼쪽 스틱 이동, 오른쪽 스틱 30도 회전, 컨트롤러로 바닥을 가리키고 트리거를 눌렀다 놓으면 15m 이내 보이는 바닥으로 이동. 종료는 헤드셋의 시스템 메뉴.

브라우저의 VR 접근 권한창은 브라우저가 표시합니다. 별도의 VR 버튼이나 HUD는 없습니다.
WebXR은 HTTPS 또는 localhost에서 사용할 수 있습니다. 헤드셋을 사용하지 않는 PC·모바일에서는 일반 3D 탐색으로 동작합니다.
실제 헤드셋에서의 입체 표시와 컨트롤러 동작은 기기 검증이 필요합니다.
