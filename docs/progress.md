# 진행 상태

## 2026-11-22: UI 없는 공간 VR로 교체

사용자의 명시적 요청에 따라 기존 앱·서버·UI·자산·문서를 새 공간 VR 프로젝트로 교체했습니다. 이전 파일은 Git 이력에 보존됩니다.

- 원본 `공간.glb`를 `public/models/space.glb`로 보존했습니다.
- 사람 눈높이 탐색, PC·모바일 입력, WebXR 헤드셋·컨트롤러 입력을 포함합니다.
- 화면에는 렌더링 캔버스만 표시합니다.
- GitHub Pages `/XR/` 모델 경로와 main 자동 배포 워크플로를 구성했습니다.
- Node 검사에서는 원본 SHA-256, 실제 GLTFLoader 로딩, 시작점 바닥·전방 여유 공간, 데크·계단 높이를 확인합니다.
- 최종 검사 명령: `VITE_BASE_PATH=/XR/ npm run check`.
- 검사 결과: JavaScript 문법 검사, 실제 모델 검사 3개, Vite 프로덕션 빌드 통과. 빌드 HTML·스크립트의 `/XR/` 자산 경로와 배포 모델의 원본 SHA-256 일치도 확인했습니다.

브라우저 화면과 실제 VR 기기의 입체 표시·컨트롤러는 직접 검증하지 못했습니다. 이전의 멀티플레이·서버 기능은 새 프로젝트의 범위에 포함되지 않습니다.

## 2026-11-22: 블루길 벨벳 카펫·두 배 확장·평탄화

- 격자 줄눈을 제거하고, 미세한 비방향성 파일 요철과 부드러운 sheen을 가진 파란 벨벳 카펫 재질을 적용했습니다.
- 외곽 반경 31.7m는 유지하고 내곽 반경을 26.7m에서 21.7m로 줄여 블루길 폭을 5m에서 10m로 넓혔습니다.
- 주변 테라스·계단·흰색 경계 턱을 제거하고 카펫과 내부 바닥을 모두 높이 1.15m로 연결했습니다. 가구로 구성된 내부 라운지 좌석은 유지합니다.
- 기존 단 위의 가구·화분·탁상등은 원래 지지 바닥의 높이 차만큼 내려 새 바닥에 배치합니다.
- 렌더링 전에 편집하므로 표시되는 공간과 걷기·충돌·VR 바닥 이동이 동일한 장면을 사용합니다. 원본 GLB 파일은 보존합니다.
- `VITE_BASE_PATH=/XR/ npm run check` 통과: 실제 모델 검사 6개와 JavaScript 문법 검사·프로덕션 빌드. 32방향 바닥 연속성, 네 방향 옛 계단 통로의 몸 높이 충돌 부재, 폭 10m, 줄눈·턱 제거, 가구·화분 높이를 확인했습니다.
- 편집한 장면을 Blender로 별도 렌더링해 전체 형태와 바닥 연결을 확인했습니다. 이 렌더링에는 브라우저 전용 미세 bump 텍스처를 제외했습니다. 브라우저 및 실제 헤드셋 검증을 대신하지 않습니다.
- 사용자 요청에 따라 변경마다 GitHub main 업데이트와 Pages 배포 완료까지 진행합니다.

## 2026-11-22: 첨부 단면 기준으로 계단 구조 복원

앞선 전체 평탄화와 가구 하강 처리를 취소했습니다. 첨부 단면은 높은 블루길에서 원형 계단을 따라 낮은 중앙 원형 공간으로 내려가는 구조입니다. 블루길과 계단 최상단 사이의 불필요한 턱을 없애는 것으로 수정했습니다.

- 원본 원형 계단 메시 9개와 그 위의 가구·화분 높이를 복원하고, 계단도 실제 보행·VR 바닥으로 사용합니다.
- 중앙 바닥 높이 1.15m, 계단 상단·블루길 높이 1.99m를 유지합니다. 전체 높이를 같게 만들지 않습니다.
- 최상단 계단 외곽의 틈을 높이 1.99m의 연결 바닥으로 메우고, 흰 경계 장식 턱과 기존 줄눈은 제거합니다.
- 중앙 공간과 원형 계단의 면적을 유지하기 위해 블루길은 내곽 반경 26.7m부터 바깥으로 10m 확장합니다. 외곽 벽도 5m 바깥으로 이동하고 벽 하부 높이를 블루길에 맞춥니다. PC·VR 이동 반경도 확장합니다.
- 무늬 없는 벨벳 재질과 UI 없는 화면은 유지합니다.
- `VITE_BASE_PATH=/XR/ npm run check` 통과: 모델 검사 8개·문법 검사·프로덕션 빌드. 중앙→계단→상부 블루길 단면, 상단 접점의 동일 높이, 계단 상하 이동, 확장 폭과 이동 반경을 확인했습니다.
- 렌더링은 별도 Blender 형태 검증이며 브라우저·실제 VR 기기 검증과 구분합니다.
