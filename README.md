# 공간 VR

배포 주소: https://mango040730.github.io/XR/

`공간.glb`를 바탕으로 만든 UI 없는 WebXR 공간입니다.
화면에는 3D 캔버스만 표시됩니다. 상부는 지붕 없이 열려 있으며 파란 상부 배경 대신 밝은 중립색 배경을 사용합니다. 원본은 `public/models/space.glb`에 보존했습니다.

단면은 **높은 블루길 → 원형 계단 공간 → 낮은 중앙 원형 공간**입니다. 직전 가운데 좌석 층의 높이 약 5.63m를 새 최고 높이로 삼아 전체 3개 좌석 층을 고르게 낮췄습니다. 중앙 앞쪽 바닥은 높이 1.15m를 유지하며 총 단차는 약 6.72m에서 4.48m로 줄었습니다. 원형 단의 바닥 높이는 안쪽부터 약 2.64·4.14·5.63m이며 각 단 차이는 약 1.49m입니다. 블루길은 격자 없는 벨벳 카펫이며 가장 바깥 좌석 단과 같은 약 5.63m 높이로 이어집니다. 책상과 의자는 아래 두 단에만 배치하고 맨윗단은 가구 없이 비워 둡니다. 높이는 `src/space-levels.js`에서 함께 관리합니다.

중앙 라운지는 참고 이미지의 곡선 소파·원형 좌석·식재 배치를 유지합니다. 가운데 굽은 경계는 실제 바닥 단차이며, 이미지의 뒤쪽 바닥이 앞쪽보다 0.28m 높은 1.43m입니다. 뒤쪽 가구와 화분도 같은 높이로 올려 접지시켰습니다. 두 바닥은 같은 #F4CFB8 재질을 사용하고 단의 수직면은 #FDE8DC입니다. X 표시된 앞 오른쪽 긴 테이블·의자·소품과 흰 콩 모양 블록, 경계를 대신하던 별도 블록은 제거했습니다. 실제 채워진 바닥을 보행·충돌·VR 이동에 공통으로 사용합니다.

네 방향의 좁은 이동 계단은 15단으로 한 단 높이 약 0.30m, 디딤 깊이 약 0.60m입니다. 넓은 원형 좌석 계단(3단)과 하나의 연속된 형상으로 연결되며 위쪽 면과 높이가 다른 측면까지 빈틈없이 이어집니다. 가장 바깥 단과 블루길도 같은 외곽선을 공유합니다.

원형 단의 깊이는 3m, 전체 공간 지름은 90.4m, 중앙 바닥 반경은 26.2m입니다. 책상과 의자는 아래 두 단에만 있으며 맨윗단의 가구는 제거했습니다. 아래층 책상 28개·가운데층 32개로 총 60개이고, 1인용 11개·2인용 17개·3인용 15개·4인용 17개로 총 158석입니다. 기존 일체형 상판·앞쪽 턱/앞판·양끝 지지판을 유지하며 책상과 의자는 #E99804입니다. 책상은 나뭇결과 요철 없는 골드 단색 표면을 사용합니다. 가구가 있는 두 단 둘레의 80% 이상을 채우고 책상 간격 약 0.35m, 의자 뒤 1.2m 통로와 네 이동 계단을 유지합니다. 의자는 중앙을 보는 바깥쪽 한 줄에만 있으며 원형 스툴 2개는 제거된 상태입니다. 큰 화분은 블루길 안쪽에 있습니다.

사용자 지정 색상은 `src/space-colors.js`에서 관리합니다. 중앙 코랄 좌석 #ED715D, 계단 책상·의자 #E99804, 중앙 바닥 #F4CFB8, 조형물·소파 등받이·구조물 #FDE8DC, 원형 블루길/레일 #1A3880입니다. 책상이 있는 아래 두 원형 단과 좁은 이동 계단은 연그레이 #D9DADD이며, 책상 없는 넓은 최상단의 윗면만 블루레일과 같은 #1A3880 카펫이며, 그 아래 수직 앞면·계단 옆면·밑면은 이전 연그레이 #D9DADD입니다. 최상단과 이동 계단의 마지막 디딤면은 레일의 재질과 표면 좌표를 공유해 블루로 이어집니다. 원본에서 한 재질로 묶인 소파 좌판·등받이는 형상을 유지한 채 부품별 색상으로 구분했습니다.

블루길은 폭 10m를 유지합니다(내곽 반경 35.2m, 외곽 반경 45.2m). 외곽 벽과 이동 범위도 함께 확장했습니다. 원형 계단·블루길 모두 보행·VR 이동이 가능하며 UI는 추가하지 않습니다. 편집은 `src/prepare-space.js`에서 원본 로딩 후 적용합니다.

외곽 벽은 높이 6.8m의 360도 원형 디지털 스크린입니다. 얇은 프레임과 은은한 발광·광택으로 빈 대기 화면만 표현하며, UI나 문구는 넣지 않았습니다. 기존 반원 벽의 간판·문·기둥·파도 장식은 제거했습니다. `src/digital-wall.js`의 연속된 단일 화면 표면에 추후 콘텐츠를 적용할 수 있습니다.

공간은 최신 참고 이미지의 매끈한 제품 렌더 미니어처 스타일입니다. 소파·쿠션·둥근 좌석 부품은 실제 곡면을 부드럽게 다듬고 각 부품의 원래 외곽과 크기를 유지합니다. 주 소파의 쿠션 메시를 69,320개에서 277,280개 삼각형으로 세분화하고, 좌판에 완만한 볼륨과 55개 좌판의 같은 색상 마감선을 추가했습니다. 계단 책상 베벨은 12개 곡면 구간과 연속된 노멀을 사용하고, 다른 가구의 베벨은 각도 가중 노멀을 사용해 큰 면과 둥근 모서리 사이의 반사광을 자연스럽게 잇습니다. 책상은 3.5cm의 둥근 베벨을 사용합니다. 소파는 부드러운 반무광 패브릭, 계단 책상은 나뭇결 없는 지정 골드 단색 마감, 나머지 가구 프레임은 도장, 화분은 새틴 도자기, 하부 받침은 금속으로 재질별 광택을 구분합니다. 차분한 식재 색상과 따뜻한 중립색 배경을 사용하며, 과한 밝기를 낮춘 주광·환경 반사와 부드러운 그림자로 입체감을 표현합니다. 사용자 지정 팔레트와 공간 구성·통로를 유지합니다. 스타일 처리는 `src/clay-style.js`에서 적용하며 디지털 스크린과 블루 벨벳은 기존 재질을 유지합니다.

가구에는 실제 곡면 세분화를 적용하며 자갈 186개와 가구 다리·프레임 1,028개는 매끄러운 입체로 표현합니다. 식물은 `src/botanical.js`에서 11개 기존 화분 안에 별도로 구성합니다. 34개의 휘어진 목질 줄기와 분지된 가지에 878개의 얇고 끝이 좁아지는 잎을 연결했습니다. 잎은 앞뒷면·중앙 잎맥·보조 잎맥의 굴곡·잎자루를 가지고, 수관과 새순·낮은 잎·탁상 화분을 구분합니다. 성숙한 잎은 깊은 녹색, 새순은 밝은 녹색을 사용하며 원래 화분 위치와 보행 공간을 유지합니다. 좌판 마감선은 길이 64구간·단면 12구간입니다. 전체 장면은 약 338만 삼각형(상한 340만)으로 관리합니다.

브라우저 화면은 `src/studio-renderer.js`에서 HDR·멀티샘플링과 GTAO 접촉 음영을 합성합니다. 그림자는 VSM 필터를 사용해 넓은 바닥에 생기던 자기 그림자 줄무늬를 줄입니다. 발광 디지털 스크린은 접촉 음영 대상에서 제외하고 뒤쪽 하우징과 간격을 확보했습니다. 모바일 화면 크기가 바뀌면 합성 버퍼도 함께 조정합니다. VR에서는 WebXR의 양안 렌더링을 직접 사용하며 화면 기반 GTAO 합성은 사용하지 않습니다. 모델 곡면·재질·VSM 그림자는 VR에도 동일하게 적용됩니다.

## 실행

```sh
npm install
npm run dev
```

배포용 빌드: `npm run build` (`dist/`).

검사: `npm run check`. GitHub의 main 브랜치에 업로드하면 Actions에서 검사·빌드 후 GitHub Pages로 자동 배포합니다. Pages 빌드는 `VITE_BASE_PATH=/XR/`로 실행합니다.

## 조작

- PC: 화면 클릭 후 마우스로 둘러보기, WASD/방향키 이동, Shift 빠르게 걷기, Esc 마우스 해제, R 시작 위치.
- 모바일: 한 손가락 드래그로 둘러보기, 두 손가락을 대고 있으면 앞으로 이동.
- WebXR 지원 헤드셋: HTTPS 주소를 헤드셋 브라우저에서 열고 공간을 클릭하면 VR 진입. 키보드가 있다면 V로도 진입.
- VR: 왼쪽 스틱 이동, 오른쪽 스틱 30도 회전, 컨트롤러로 바닥을 가리키고 트리거를 눌렀다 놓으면 15m 이내 보이는 바닥으로 이동. 종료는 헤드셋의 시스템 메뉴.

브라우저의 VR 접근 권한창은 브라우저가 표시합니다. 별도의 VR 버튼이나 HUD는 없습니다.
WebXR은 HTTPS 또는 localhost에서 사용할 수 있습니다. 헤드셋을 사용하지 않는 PC·모바일에서는 일반 3D 탐색으로 동작합니다.
실제 헤드셋에서의 입체 표시와 컨트롤러 동작은 기기 검증이 필요합니다.

충돌 계산은 `src/collision.js`에서 GLB의 인덱스 메시와 새로 생성한 비인덱스 바닥을 같은 형식으로 변환한 뒤 병합합니다. 모델 검사에는 실제 런타임 병합 및 시작점 이동 경로 검사가 포함됩니다. 별도 Chrome을 `--headless=new --remote-debugging-port=9223 --user-data-dir=/private/tmp/gonggan-movement-chrome`로 실행한 환경에서는 `node scripts/check-browser-movement.mjs <검증할 URL>`로 W/S·방향키·두 손가락 터치 이동과 브라우저 예외를 검증할 수 있습니다.
