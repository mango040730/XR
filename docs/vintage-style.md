# 빈티지 틸·월넛 팔레트와 라이팅

2026-11-08. 이번 메시지에는 새 레퍼런스 이미지가 표시되지 않아 사용자가 명시한 HEX와 아트 디렉션을 기준으로 조정했습니다. 현재 실내 낚시터의 구조와 가구·캐릭터 위치, 카메라, 이동, 착석과 낚시, UI는 유지했습니다.

## 컬러와 재질

`src/worlds/indoor-fishing/style.ts`에서 공통 팔레트와 조명 값을 관리합니다.

| 역할 | 핵심 색상 | 적용 |
| --- | --- | --- |
| Dusty Teal | #6F918D | 벽, 수조 벽 |
| Deep Teal | #426864 | 장비함, 소품, 어두운 청록 마감 |
| Honey Brown | #A27A48 | 천장, 일부 작은 마감 |
| Dark Walnut | #39271E | 기둥·보·창틀·문·선반·의자 골조 |
| Warm Ivory | #D1C7AD | 테두리, 타일 줄눈, 밝은 장식 |
| Charcoal | #30312D | 낚싯대와 금속 부품 |
| Amber | #EBC48A | 펜던트와 반사 하이라이트의 광원 |

기존 황갈색 바닥은 저채도 청록 계열 타일로, 밝은 노랑 목재는 다크 월넛으로 정리했습니다. 인물과 장비도 같은 팔레트의 제한된 보조색을 사용합니다. 실제 수중 테라코타 타일은 기존 물 레퍼런스를 유지하며 줄눈만 아이보리로 맞췄습니다.

`materials.ts`는 MeshStandardMaterial의 기본 조명·그림자 계산을 유지하며 거칠기와 금속성을 분리합니다. 목재에는 월드 좌표 기반의 약한 결을, 도장과 타일에는 미세한 색·거칠기 변화를 추가했습니다. 멀리 있는 나뭇결은 화면 미분값으로 강도를 낮춥니다. 추가 이미지 다운로드나 고해상도 텍스처는 없습니다. 기존 베벨 세그먼트 2와 평평한 면을 유지합니다.

## 빛과 음영

- 오후 햇살: 창문 바깥 `[-9, 6, -8]`에서 `[1, 0, 0]` 방향. 직사광 3.0과 따뜻한 중립색으로 창틀·가구의 뚜렷한 그림자를 만듭니다.
- 중립적인 반구광은 1.2에서 0.8로 줄였습니다. 창가 보조광 0.85와 약한 위쪽 바닥 반사광 0.5는 간접광을 근사합니다. 실시간 전역 조명 계산은 아닙니다.
- 기존 펜던트 6개 위치에 앰버 SpotLight와 약한 PointLight 반사광을 연결했습니다. 펜던트 아래가 밝고 거리와 각도에 따라 감쇠합니다. 두 펜던트만 1024² 그림자 맵을 사용해 비용을 제한합니다.
- 햇빛 그림자 4096², 직교 범위 22×18m, 법선 바이어스 0.012m로 접점의 떠 보임을 줄였습니다. 설치된 Three r187의 PCFShadowMap을 명시적으로 사용합니다. 맵은 기존 방식대로 캐시하고 월드·표시 상태 변경 때 갱신합니다.
- `ambientOcclusion.ts`는 월드 생성 시 주변 불투명 메시의 경계 상자를 공간 격자에 넣고, 0.36m 안의 8방향 가림을 계산해 버텍스에 저장합니다. 간접광에만 적용하므로 햇빛을 검게 칠하지 않습니다. 경계 상자를 사용한 정적 근사 AO이며 전체 삼각형 기반 GI나 동적 SSAO는 아닙니다.
- 의자 12개와 선반 2곳에는 월드 안에서 공유하는 64² 감쇠 텍스처로 부드러운 접촉 음영을 추가했습니다. 깊이 쓰기를 끄고 기존 바닥보다 위에 배치했습니다. 버텍스 AO와 접촉 음영에는 추가 화면 렌더 타깃이나 후처리 패스가 필요하지 않습니다. 접촉 음영 메시 14개는 각 시점의 일반 장면 렌더링에 포함됩니다.
- 노출 1.0, Bloom 0.055. 최초 검수에서 그늘이 과도하게 어두웠던 문제를 보조광으로 수정하고 청록과 월넛의 구분을 재확인했습니다.

`ClearWater.ts`, `WaterScene.ts`, `waterShaders.ts`, 물결·굴절·반사·깊이 설정과 낚시 타이밍 코드는 수정하지 않았습니다. 새 광원과 주변 재질은 기존 물의 실제 장면 캡처에 자연스럽게 반영됩니다. 사용하지 않는 Kit 재질은 생성 마무리에서 정리하며 새 텍스처와 그림자 자원도 월드 퇴장 때 해제됩니다.

## 검증

- Node: 단위 17개 파일 / 95개 검사, 린트·타입·GLB 자산 검사·프로덕션 빌드 통과. 재질 분리, 가까운 가구 아래 AO와 열린 바닥의 차이, 지오메트리 불변, 광원과 그림자 개수 및 자원 정리를 검사했습니다.
- 브라우저: Chromium 158 / Apple M4 / ANGLE Metal, 실제 GPU E2E 4개 통과. WASD·시점 회전·충돌·착석·투입·포획·회수·일어나기, 양쪽 수조와 면 겹침, 물 품질 전환, 데스크톱과 모바일 화면을 검사했습니다. [브라우저 기록](vintage-browser.json).
- 프레임 관측: 1440×1000, 기본 품질에서 워밍업 뒤 60개 rAF 간격 중앙값 16.7ms / 95백분위 17.6ms. 헤드리스 Chromium의 단일 장면 관측값으로, GPU 타이머 측정이나 VR 성능 보장은 아닙니다. [관측 기록](vintage-performance.json).
- 소프트웨어 WebGL: 기본 Chromium / SwiftShader 물 렌더링 E2E 1개 통과. 셰이더 컴파일·양쪽 시점·품질 전환·모바일 화면·오류 로그를 검사했습니다. [소프트웨어 기록](vintage-software-browser.json).
- Safari 및 실제 VR 헤드셋: 미검증. 낮은 품질·모바일 화면은 기존 직접 렌더링 경로를 유지합니다.
