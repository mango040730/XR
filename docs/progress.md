## 2026-11-22: UI 없는 공간 VR로 교체

사용자의 명시적 요청에 따라 기존 앱·서버·UI·자산·문서를 새 공간 VR 프로젝트로 교체했습니다. 이전 파일은 Git 이력에 보존됩니다.

- 원본 `공간.glb`를 `public/models/space.glb`로 보존했습니다.
- 사람 눈높이 탐색, PC·모바일 입력, WebXR 헤드셋·컨트롤러 입력을 포함합니다.
- 화면에는 렌더링 캔버스만 표시합니다.
- GitHub Pages `/XR/` 모델 경로와 main 자동 배포 워크플로를 구성했습니다.
- Node 검사에서는 원본 SHA-256, 실제 GLTFLoader 로딩, 시작점 바닥·전방 여유 공간, 데크·계단 높이를 확인합니다.
- 최종 검사 명령: `VITE_BASE_PATH=/XR/ npm run check`.
- 검사 결과: JavaScript 문법 검사, 실제 모델 검사 3개, Vite 프로덕션 빌드 통과. 빌드 HTML·스크립트의 `/XR/` 자산 경로와 배포 모델의 원본 SHA-256 일치도 확인했습니다.

브라우저 화면과 실제 VR 기기의 입체 표시·컨트롤러는 직접 검증하지 못했습니다. 이전의 멀티플레이·서버 기능은 새 프로젝트의 범위에 포함되지 않습니다.
