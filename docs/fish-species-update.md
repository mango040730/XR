# 수조 바닥·어종·포획 대기 개선

2026-11-09. 수조 바닥을 벽과 같은 색으로 통일하고 병어·고등어·숭어 모델과 30초~2분 무작위 포획을 적용했습니다.

## 수중 바닥

수중 타일 240개는 실내 벽과 같은 `palette.wall`(#F4EEE6)을 사용합니다. 줄눈 받침도 같은 밝은 팔레트이며 수면 아래 타일 높이는 기존 -0.65m, 수면은 0.385m로 유지했습니다. 흰 바닥에서 타일의 얇은 옆면이 점선처럼 보이는 현상을 직접 확인해 받침은 상판보다 2mm 낮게 두고 실제 타일 상판만 렌더링하도록 정리했습니다. 물속 바닥은 수면과 별도 지오메트리이며, 물의 반사·굴절·투명도·파동 설정은 유지했습니다. 조명과 물의 흡수 때문에 화면에서 보이는 밝기는 벽과 다를 수 있으나 기본 색상 값은 동일합니다.

## 어종과 모델

`fishSpecies.ts`의 공통 목록을 수영 모델·포획 결과·포획 애니메이션이 함께 참조합니다. 수조에는 각 어종 두 마리씩 총 여섯 마리가 있습니다.

- 병어: 넓고 옆으로 납작한 은빛 몸, 길게 휘는 위·아래 지느러미와 작은 입.
- 고등어: 유선형 몸, 청록색 등과 어두운 물결무늬, 꼬리 앞 작은 지느러미.
- 숭어: 두툼한 머리와 몸, 분리된 등지느러미, 옆면의 은은한 줄무늬와 입술.

원래의 단순한 구·삼각 꼬리를 어종별 단면을 따라 만든 몸통, 갈라진 꼬리, 가슴지느러미, 눈·아가미·입 디테일로 교체했습니다. 은빛 재질과 매끄러운 법선, 등/옆/배의 색 차이를 적용했습니다. 무늬와 작은 몸통 굴곡은 GLSL에서 계산하고 꼬리·지느러미는 관절로 움직입니다. 매 프레임 몸통 버퍼를 다시 생성하지 않습니다.

같은 월드 안에서 정적 모델 지오메트리와 디테일 재질을 공유하며, 어종별 GPU 프로그램은 재사용합니다. 각 개체는 별도의 애니메이션 uniform을 사용하고 기존 수면 캡처에서도 같은 움직임을 표시합니다. 전역 GPU 자원 캐시나 외부 모델·텍스처 다운로드, 새 라이브러리는 추가하지 않았습니다. 잡힌 물고기는 결과의 `species`와 같은 모델만 표시합니다.

## 포획 시간과 결과

`CATCH_WAIT`는 30,000~120,000ms이고 매 투입 때 새 대기 시간을 뽑습니다. 매 프레임 기한을 확인하므로 회수·일어나기·자리 변경·퇴장 시 대기가 취소되며, 백그라운드에서 돌아와도 포획을 중복 처리하지 않습니다. 안내 패널과 투입 메시지도 공통 `CATCH_WAIT_LABEL`의 30초~2분으로 갱신했습니다. 병어 20~32cm, 고등어 25~45cm, 숭어 35~65cm는 게임 표시용 크기 범위이며 자연계의 최대 크기 제한을 뜻하지 않습니다.

## 검증

- `npm run check`: 20개 파일 / 105개 단위 검사, 린트·타입·자산·빌드 통과. 29,999ms 이전 미포획/30,000ms 하한, 120,000ms 상한, 재투입·취소·중복 방지, 세 어종 선택과 크기 범위를 검사했습니다.
- 실제 메시: 어종별 실루엣, 바깥 방향 법선과 유효 좌표, 공유 버퍼 불변·월드별 자원 해제, 모든 유영 모델의 수면/바닥/벽 침범 방지, 포획 결과와 표시 모델 일치를 검사했습니다. 모든 타일의 기본색이 벽과 같음도 검사했습니다.
- Chromium 158 / Apple M4 / ANGLE Metal: 실제 WASD·착석·투입·포획·회수·일어나기와 물 품질 전환/모바일 회귀 2개 통과. 상판 조정 후 물 렌더링을 다시 확인했습니다.
- 실행 중인 5174 서버: 수조/어종 렌더링·새 안내·전체 갱신, 실제 착석과 새 시간 범위 포획 검사 2개 통과. 브라우저 가상 시계를 28초와 120초 구간으로 진행하며 상태를 관측했고, 게임 상태를 직접 바꾸는 디버그 어댑터는 사용하지 않았습니다. 실제 고등어 모델과 포획 문구가 일치하는 캡처를 확인했습니다.
- Safari와 실제 VR 헤드셋은 미검증입니다.
